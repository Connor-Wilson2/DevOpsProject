# DevOpsProject

Project Proposal: Warhammer 40,000 Collection Manager 

For my software development project, I propose creating a Java application that allows Warhammer 40,000 
players to catalog, organize, and track their miniature collections. 
The application will provide a user interface where users can enter information about each unit they own,
including faction, unit name, number of models in the unit, and individual wargear options for each model.
The system will store this data in a database, allowing users to maintain a record of their collections and 
update it as new miniatures are acquired, or existing units are modified. 

The application will also generate reports that group units by faction and display available
unit configurations within the user's collection. This feature will help players quickly determine which 
armies they can field and what equipment options are available when building army lists for games. 
The project will require classes representing factions, units, models, and wargear, while also needing a database, 
data validation, and search/filter functionality. The final product will provide a practical tool for myself and others.
